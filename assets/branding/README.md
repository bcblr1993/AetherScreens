# AetherScreens v1 identity

Two rounded screen outlines interlock into an S, connecting desktop and mobile.
The white upper screen and cyan lower screen sit on midnight navy.

- `app-icon-v1.png`: original square artwork for the website and iOS source.
- `mac-icon-v1.png`: macOS squircle with transparent outer margins.
- `AppIcon-v1.icns`: 16–1024 px macOS representations.
- `ios/Assets.xcassets/AppIcon.appiconset`: opaque 1024 px iOS icon; the OS applies its mask.

Keep the mark square, preserve its proportions, and use the supplied artwork.
Do not add text, extra shadows, or a second outline inside the icon.
Use SF Symbols for interface actions; the product mark identifies the application.
